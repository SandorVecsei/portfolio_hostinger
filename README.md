# GLM Creative Agency Portfolio

An Awwwards-style creative agency portfolio website built with Next.js (App Router), React, and Framer Motion.

## Includes

- Modern motion-heavy homepage
- Route-level page transitions
- Portfolio index page
- Dynamic individual portfolio pages with case-study content
- Studio/about page
- Responsive layout for desktop and mobile

## Run locally

1. Install Node.js 20+
2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

4. Open `http://localhost:3000`
